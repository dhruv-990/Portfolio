# Portfolio

A fast, accessible, single‑page portfolio powered by static HTML and Tailwind via CDN.

## Getting started

- Open `index.html` directly in your browser, or
- Serve locally:

```bash
cd /workspace/portfolio
python3 -m http.server 5173
# open http://localhost:5173
```

## Customize

- Replace placeholders (name, links, copy) in `index.html`.
- Drop your images into `assets/img/` and update the `src` paths.
- Add your résumé at `assets/YourName-Resume.pdf` and update the link.

## Deploy

Host on any static host (GitHub Pages, Netlify, Vercel). No build step required.
